# Qibla Direction

Программа для вычисления направления на Каабу и визуализации его на карте с ориентацией здания.

## Возможности

- Вычисление направления на Каабу тремя методами (spherical, Vincenty, great circle)
- Автоматическое определение ориентации здания по полигону из OpenStreetMap
- Генерация карты с визуализацией направления и инструкциями по повороту
- Автоматическое получение адреса для имени файла
- Поддержка Яндекс.Карт и CartoDB (автоматический fallback)

## Установка

```bash
pip install -r requirements.txt
```

## Использование

```bash
python -m bearing.cli <lat> <lon> [опции]
```

### Параметры

- `lat`, `lon` - Координаты точки (поддерживаются точка и запятая как разделитель)
- `-o, --output` - Путь для сохранения (по умолчанию: генерируется на основе адреса)
- `-z, --zoom` - Уровень зума (по умолчанию: 19)
- `-r, --radius` - Радиус поиска здания в метрах (по умолчанию: 150)
- `-s, --size` - Размер изображения в пикселях (по умолчанию: 900)
- `--tile-source` - Источник карты: `yandex` или `cartodb` (по умолчанию: `yandex`)

### Примеры

```bash
# Базовое использование
python -m bearing.cli 42.96914 47.49389

# С указанием параметров
python -m bearing.cli 42.96914 47.49389 -z 20 -r 200

# Координаты с запятой
python -m bearing.cli 42,96914 47,49389
```

## Зависимости

- `requests` - HTTP запросы
- `Pillow` - Работа с изображениями
- `numpy` - Математические вычисления

## Особенности

- **Автоматический fallback**: При проблемах с Яндекс API автоматически используется CartoDB
- **Единообразие карты**: Если часть тайлов Яндекс API пустые, все тайлы перезагружаются через CartoDB
- **Точность расчетов**: Три метода вычисления bearing для сравнения
- **Умное имя файла**: Автоматическая генерация имени на основе адреса или координат

## Источники данных

- **Карты**: Яндекс.Карты API (с fallback на CartoDB)
- **Здания**: OpenStreetMap через Overpass API
- **Адреса**: Nominatim (OSM) с fallback на Яндекс Geocoder

## Лицензия

Проект использует данные OpenStreetMap (лицензия ODbL).
